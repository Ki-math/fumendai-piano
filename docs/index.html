曲

両手の大譜表で練習できます。手持ちの楽譜データ（MusicXML・MIDI）も読み込めます。

楽譜データの入手先　著作権の切れたクラシック曲は IMSLP や MuseScore の公開楽譜から MusicXML・MIDI で入手できます。楽譜ソフトで作った譜面も「MusicXMLで書き出し」で読み込めます。ピアノ譜（2段）はト音記号を右手、ヘ音記号を左手として扱います。

レッスン

5本の指の位置からスケール・和音・読譜まで、順番に進めるコースです。テンポモードで100%・正確さ95%以上を取ると★3つになります。
