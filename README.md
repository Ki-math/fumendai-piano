# 譜面台ピアノ

iPad を譜面台に置いて、本物のピアノで両手の練習をするための Web アプリです。
インストール不要で、Safari で開いて「ホーム画面に追加」すればアプリとして使えます。

**▶ アプリを開く:** https://ki-math.github.io/fumendai-piano/

## できること

| 機能 | 内容 |
|---|---|
| 大譜表 | ト音記号＋ヘ音記号の2段譜。調号・臨時記号・和音・付点・休符・タイ・指番号を表示 |
| 入力 | **マイク**（iPad のマイクで本物のピアノの音を聴き取る）／**電子ピアノ**（USB・Bluetooth MIDI）／画面の鍵盤 |
| ウェイトモード | 正しい鍵盤（和音はすべて）を押すまで待つ。自分のペースで音を確かめる |
| テンポモード | メトロノームに合わせて弾き、タイミングのずれを ms 単位で判定 |
| 片手練習 | 右手・左手・両手を選択。練習しない手はアプリが伴奏 |
| A–B リピート | 小節をタップして範囲を選び、くり返し練習。「だんだん速く」で正確さ90%以上ならテンポを5%ずつ上げる |
| 曲の読み込み | MusicXML（`.musicxml` `.xml` `.mxl`）と MIDI（`.mid`）。ピアノ譜は上段＝右手、下段＝左手 |
| レッスン | 5本指の位置 → スケール（ハ・ト・ヘ長調）→ 三和音 → アルペジオ → リズム → 読譜ドリルの13ステップ |
| 練習記録 | 弾いている時間だけを数え、日ごとのグラフ・連続日数・履歴・★（3段階）を保存 |

## iPad での使い方

1. Safari で上のリンクを開き、共有ボタン →「ホーム画面に追加」
2. ホーム画面のアイコンから起動（アドレスバーのない全画面、オフラインでも起動できます）
3. 曲を選び、表示される案内から「マイクをオン」→ マイクを許可
4. iPad を譜面台に置き、ピアノを弾く

### 入力ごとの違い

| 入力 | 判定できること | 使える端末 |
|---|---|---|
| マイク | 単音の音の高さ（和音は1音合えば進む・オクターブ違いは正解扱い） | iPad / iPhone / PC（https で開いたとき） |
| 電子ピアノ（MIDI） | 和音・両手・オクターブまで正確に判定 | PC の Chrome / Edge、Android の Chrome |
| 画面の鍵盤 | すべて | すべて |

> iPad のブラウザは Safari を含めて Web MIDI に対応していないため、iPad で電子ピアノを MIDI 接続することはできません。電子ピアノをお使いの場合も、iPad ではマイク入力で練習できます。

マイクの判定が遅れて感じるときは、設定の「マイクの遅れ補正」を調整してください。

## 開発

依存パッケージはありません。`src/` を編集して、ビルドすると `docs/`（GitHub Pages の公開フォルダ）に出力されます。

```sh
python3 build.py              # docs/ に書き出す
cd docs && python3 -m http.server 8000   # http://localhost:8000 で確認
```

### 構成

| ファイル | 役割 |
|---|---|
| `src/theory.js` | 音名・MIDI番号・調号・五線上の位置の変換 |
| `src/score.js` | 楽譜データの形と、テキスト譜（`C4/h [C3 E3 G3]/w` など）からの生成 |
| `src/library.js` | 内蔵の曲とレッスン |
| `src/importers.js` | MIDI / MusicXML / .mxl の読み込み |
| `src/audio.js` | 音の再生（お手本・伴奏・メトロノーム）と、マイクの音程検出（NSDF法） |
| `src/input.js` | 電子ピアノ・マイク・画面鍵盤の入力を1つにまとめる |
| `src/keyboard.js` | 画面下の鍵盤 |
| `src/notation.js` | 大譜表の組版と SVG 描画 |
| `src/practice.js` | 練習の進行と判定（ウェイト・テンポ・お手本・リピート） |
| `src/log.js` | 練習時間・履歴・ベスト記録の保存（端末のブラウザ内） |
| `src/app.js` | 画面の組み立てと操作 |
| `src/shell.html` | 画面の骨組みとスタイル |
| `static/` | アイコン・Web App Manifest・Service Worker |

練習記録と読み込んだ曲は、その端末のブラウザ内（localStorage）にだけ保存されます。

内蔵曲の旋律はいずれもパブリックドメインで、左手の伴奏はこのアプリ用の編曲です。
